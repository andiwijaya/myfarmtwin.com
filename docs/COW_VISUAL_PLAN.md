# Cow Barn visual and interaction baseline

Baseline reviewed actual fresh local screenshots `qa/cow/M0-F04/chicken/navigation-desktop-en.png` and `camera-mobile-yard180.png`, full original responsive camera suite, twelve baseline performance surfaces and prior exact-production Goat camera evidence. The existing game is a lightweight SVG isometric 8x8 world, not 3D/WebGL. Preserve the cream/forest/sage palette, paper panels, original in-game FarmGirl, map size and shared HUD. Existing low-graphics and reduced-motion modes already disable decorative motion without model changes.

Create original SVG code-native shapes, no downloaded/copied/licensed media or new package: open cutaway barn with muted brick roof, straw rest pad, fence, two distinctly marked adult cows (third only from actual ownership), feed/water troughs, clean brush, gentle milking stand, milk can, optional tank and co-op sign. Reserve station/cow footprints to avoid visual/picking overlap in all four camera rotations; keep foreground fence noninteractive. Animals use stable saved IDs, small CSS idle/walk/eat/drink/rest transitions, no resource timers or model writes.

Re-use independent per-area pan, four-step rotation, zoom/reset and the existing actual-coordinate picking. Provide labelled 44px shortcuts for every object, keyboard activation/Escape/focus return, clear HUD and disabled reasons. On 320–390px mobile reserve the camera row and let the scene size intrinsically; shortcuts flow below the map, contextual panel below the world, and no touch-scroll trap unless Move is explicitly enabled. On desktop keep a generous map with compact contextual controls. Add EN/ID for every Cow action, accessible name, mission and disclosure; locale/camera changes cannot write farm resources.

M1 demonstrates actual area/ownership and contextual view only; it must not claim a working milk/sale model before M2/M3. Keep one homepage card and its existing artwork/copy unchanged until a future authorized release is actually live verified. Cow animals are adult post-calving/lactating, never calves; friendly milking has no anatomical/medical visuals. On-device performance and Safari remain unverified until real runners are available; headless evidence is labelled as such.
