# Fish visual assets

fish-scene.js is an original code-native SVG pond prototype, authored for this repository. Reuses only this project's existing isometric projection and palette. No downloaded/ripped/raster asset, attribution obligation, font, runtime package or renderer dependency was introduced. Existing media untouched. A 750x420 viewBox and fluid SVG fit320-1440px layouts; this is a clearly labelled presentation preview, not persisted Fish gameplay. Four geometric orientations use the same quarter-turn projection as existing farm. Actual camera/picking/controls and state-driven school will be wired in M1. Decorative icon counts represent a school, not the authoritative fish count.

Visual QA: qa/fish/M0-F06/report.json and pond-preview-{en,id}-{320,1440}.png. Current prototype is intentionally inaccessible from the live area selector. Build gate remains OFF until the vertical slice.
