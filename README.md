# MyFarmTwin.com

The lightweight static foundation for MyFarmTwin: practical growing, farm projects, useful gear, and food grown with intention.

## Local preview

Serve the `dist` directory with any static file server, for example `python -m http.server 4173 --directory dist`.

## Structure

- `dist/index.html` — homepage and initial brand experience
- `dist/styles.css` — responsive visual system
- `dist/assets/myfarmtwin-farmgirl.png` — approved homepage visual
- `dist/sitemap.xml` and `dist/robots.txt` — discovery basics

The project intentionally avoids a JavaScript framework and build dependency until real editorial content requires one.
